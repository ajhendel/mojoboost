MOJOBOOST LIGHTGBM FEATURE-COMPLETENESS TASKS
============================================

Purpose
-------

These are implementation prompts for closing the remaining gap between
MojoBoost and LightGBM's public capabilities. Copy and send ONE task at a
time, in order unless the task explicitly says it can be moved. Do not run
these tasks concurrently: many change the estimator, model, serialization,
training loop, or binding ABI.

"Feature complete" here means the parity matrix and tests created by Task 1
have no unsupported cells in the agreed v1 scope. It does not mean claiming
LightGBM's maturity, performance, platform coverage, numerical identity, or
years of compatibility. Never advertise those without evidence.

Upstream references (stable LightGBM 4.7.0 when this file was written):

- https://lightgbm.readthedocs.io/en/stable/Python-API.html
- https://lightgbm.readthedocs.io/en/stable/pythonapi/lightgbm.LGBMRegressor.html
- https://lightgbm.readthedocs.io/en/stable/pythonapi/lightgbm.Booster.html
- https://lightgbm.readthedocs.io/en/stable/Parameters.html

The first paragraph under every task is intentionally repeated so each task
can be copied independently.
