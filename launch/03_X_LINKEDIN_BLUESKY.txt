I released MojoTrees 0.1.0a2: native gradient-boosted trees written in Mojo, targeting the GPU already inside Apple Silicon Macs.

The project combines a LightGBM-familiar Python API with native CPU and GPU training. It already has a broad feature surface including sparse and categorical data, missing values, regression, classification, ranking, early stopping, callbacks, serialization, model contributions, and end-to-end GPU tree growth.

It is an experimental public alpha, not yet a production replacement for LightGBM or XGBoost. The first wheel supports CPython 3.14 on Apple Silicon with macOS 26 or newer:

pip install --pre mojotrees

I am looking for contributors and testers interested in Mojo, Apple GPU optimization, tree algorithms, Python packaging, and validation on Apple, NVIDIA, and AMD hardware.

Repository: https://github.com/mojotrees/mojotrees
PyPI: https://pypi.org/project/mojotrees/

The immediate technical priorities are persistent GPU execution, additional wheel targets, trustworthy end-to-end benchmarks, and validation across more hardware.
